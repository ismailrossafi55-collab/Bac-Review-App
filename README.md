# 📚 تطبيق مراجعة البكالوريا - Bac Review App

## وصف المشروع
تطبيق تعليمي متكامل لمساعدة الطلاب على مراجعة ودراسة مواد البكالوريا باستخدام تقنية التدكر المتباعد (Spaced Repetition).

## 🎯 المواد الدراسية
- 🧮 **MAT** - الرياضيات
- ⚗️ **PC** - الفيزياء والكيمياء
- 🧬 **SVT** - العلوم الطبيعية
- 🤔 **PH** - الفلسفة
- 🇫🇷 **FR** - اللغة الفرنسية
- 📖 **AR** - اللغة العربية
- ☪️ **IS** - الدراسات الإسلامية
- 🗺️ **HG** - التاريخ والجغرافيا
- 🇬🇧 **EN** - اللغة الإنجليزية

## ✨ المميزات
- ✅ إضافة المواد والدروس بسهولة
- ✅ نظام بطاقات تعليمية (Flash Cards)
- ✅ تقنية التدكر المتباعد الذكية
- ✅ تتبع التقدم والإحصائيات
- ✅ تنبيهات يومية للمراجعة
- ✅ حفظ البيانات تلقائياً

## 🛠️ التقنيات المستخدمة
- **Frontend**: React.js + Tailwind CSS
- **Backend**: Node.js + Express.js
- **Database**: MongoDB
- **Authentication**: Firebase
- **State Management**: Redux

## 🚀 كيفية البدء

### المتطلبات
- Node.js v14+
- npm أو yarn
- MongoDB

### التثبيت

#### Backend
```bash
cd backend
npm install
```

#### Frontend
```bash
cd frontend
npm install
```

### التشغيل

#### تشغيل Backend
```bash
cd backend
npm start
```

#### تشغيل Frontend
```bash
cd frontend
npm start
```
